# HTML Fundamentals Portfolio

## Project Overview

This project showcases two beginner HTML projects
completed as part of my introduction to web development.

The projects provided hands-on experience applying
foundational HTML concepts to create and structure
simple webpages.

## Projects

### 1. Birthday Invitation
A simple webpage featuring a birthday invitation,
including event details, an image, and a location link.

### 2. Movie Ranking
A webpage presenting a ranked list of favourite movies,
using headings and paragraphs to organize content.

## Skills Practiced

- Creating HTML documents
- Using headings and paragraphs
- Creating ordered and unordered lists
- Adding images
- Creating hyperlinks
- Organizing content using HTML elements
